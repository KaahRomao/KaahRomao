## 🕸️ Projetos em destaque

### [Disney Character Explorer](https://github.com/KaahRomao/Projeto-ideal)

Explorador de personagens da Disney consumindo uma API pública com `fetch` e `async/await`.

**Praticando:** JavaScript · APIs · DOM · Assincronicidade

---

### [Painel de Ferramentas](https://github.com/KaahRomao/ferramentas)

Coleção de ferramentas em JavaScript, incluindo conversores, calculadora de IMC e regra de 3.

**Praticando:** JavaScript · Lógica · Manipulação do DOM

---

### [BYKE — Orçamento de Bicicletas](https://github.com/KaahRomao/Site-de-Or-amento-de-bicicletas)

Sistema de orçamento de bicicletas com login, dashboard e fluxo de criação e visualização de pedidos.

**Praticando:** HTML · CSS · JavaScript · Interface

---

### [Clone do WhatsApp Web](https://github.com/KaahRomao/Atividade-grid-dev2n)

Recriação da interface do WhatsApp Web utilizando CSS Grid e layout responsivo.

**Praticando:** HTML · CSS · Grid · Responsividade

---

### [Salão da Jane](https://github.com/KaahRomao/SiteDajane)

Landing page para salão de beleza, com foco em composição visual, tipografia e identidade.

**Praticando:** HTML · CSS · UI · Design

---

### [Hidráulica Pro](https://github.com/KaahRomao/Folha)

Site institucional multi-página desenvolvido como projeto de prática de front-end.

**Praticando:** HTML · CSS · Estrutura de páginas
